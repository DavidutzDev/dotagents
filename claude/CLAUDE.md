# Writing

The unslop rules below apply to every response you write, not only to text you are
asked to edit. Run the pre-send check before sending, every time.

# UI

Before building, editing or auditing any interface, load the `antislop` skill plus the
depth skills the task needs: `antislop-ui` for color, layout, components and motion,
`antislop-layoutmobile` for responsive reflow, `antislop-human` for contrast, keyboard
use and UI states. They are not imported here, so a session that never touches UI pays
nothing for them.

The core filters; it does not supply taste. It works against a `DESIGN.md` or a written
brief. Without one, say the output is a draft rather than presenting it as finished.
